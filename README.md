# 한다홍 일본어 — 아이패드·아이폰 홈 화면 앱

공연장에서 바로 쓰는 일본어를 듣고 따라 말하며 외우는 개인용 앱. 주소: https://handahong.github.io/nihongo/

## 설치
1. 아이패드 **사파리**로 위 주소 열기
2. 공유 버튼 → **홈 화면에 추가**
3. 홈 화면 아이콘으로 열면 전체 화면으로 켜지고, 인터넷 없이도 동작

## 화면
- **오늘**: 복습할 카드 + 새 카드. 학습 시작 → 듣기 → 따라 말하기 → 뜻 보기 → 모름/애매/알아
- **따라 말하기**: 장면을 고르고 시작을 누르면 한 문장씩 "듣기 → 말할 시간 → 다시 듣기 → 다음"으로 손 안 대고 이어짐
- **둘러보기**: 덱·장면별 전체 목록. 재생 버튼으로 듣기, 글자를 누르면 따라 말하기 한 번
- **설정**: 하루 새 카드 수, 반복 횟수, 가나 표시, 목소리, 기록 내보내기·가져오기

## 파일
- `index.html` 앱 전부 · `decks.json` 카드 내용 · `manifest.json` 아이콘·이름 · `sw.js` 오프라인 캐시

## 카드 추가·수정
`decks.json`만 고치면 됨. 형식: `["일본어", "읽는 법(가나)", "한국어 뜻", "메모"]`.
파일을 바꿔 올린 뒤에는 `sw.js`의 `hd-nihongo-v2` 숫자와 `index.html` 위쪽 `APP_V`를 올려야 기기에 새 내용이 들어옴.

## 기록
학습 기록은 기기 안에만 저장됨. 설정 → 기록 내보내기로 가끔 파일을 남겨 둘 것.
